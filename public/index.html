₱ Pricing Configuration

Every full or partial unit of this weight is charged one Wash & Dry price. Example: at 7kg per unit and a 15kg load, the cashier is charged 3 × the base price (up to 21kg), since 15kg spans a third partial unit. Double Wash, when checked, doubles the resulting weight charge on top of that.

Each Wash & Dry unit uses this much Generic detergent and fabcon by default (doubled if Double Wash is on), and each Extra Detergent / Extra Fabcon add-on uses the same amount again. Tracked under Inventory → Auto-Tracked Usage. If a customer picks a different type — like Surf — instead, that item's own per-wash/per-scoop amounts and price (set in Inventory Items) are used instead of these Generic settings. Add or manage detergent/fabcon types under Inventory → Inventory Items.

These settings apply to every cashier station using this system.

🎟 Machine Card Settings

Each wash cycle taps the washer once and the dryer once (doubled by Double Wash, and multiplied by weight units for heavy loads). Each Extra Drying Time add-on taps the dryer again. A basic 1-load order = 1 washer tap + 1 dryer tap = ₱150 deduction by default.

🧺 Wash Only Service

Wash Only works just like Wash & Dry — priced by weight blocks, Double Wash doubles the charge, and Extra Detergent/Fabcon still apply, using the same amounts as Wash & Dry. The only difference is no dryer: no Extra Drying Time, and the card deducts this rate per load instead of the washer + dryer tap costs. Cashiers pick it from the Service dropdown on each load.

🔥 LPG (Gasul) Settings

LPG is deducted from stock automatically for every load (Wash & Dry or Wash Only) — no manual logging needed. Track it under Inventory → Gasul (LPG), stocked and restocked in kg (e.g. log a restock of 50kg for a full tank).

🗄 Cash Drawer

Open cash drawer when an order is completed
Not connected

USB direct — if you're running this on a Windows/Mac PC or laptop (not the Android tablet) with the POS-H58 plugged straight into it, this is the simplest option: no app, no pairing. Click Connect Printer once, pick your printer from the browser's device list, and Chrome/Edge remembers it from then on. Only works if your printer shows up as a USB-serial/COM port device — check Windows Device Manager under "Ports (COM & LPT)"; if it only appears under "Printers" instead, use the Windows print dialog for receipts (already supported via Print Preview) and pick RawBT or the Android bridge for the drawer instead.

Android app bridge — if you're wrapping this page in a native Android WebView, have the wrapper inject a JS object before the page loads, e.g. window.AndroidPOS = { openCashDrawer: function(){...} } (also checks window.Android.openCashDrawer and window.CashDrawer.open as fallbacks). The wrapper's native code then pulses whatever port your drawer is wired to (usually the RJ11/RJ12 kick-out port on your receipt printer).

RawBT — install the free RawBT Print Service app, pair it with your Bluetooth/USB/WiFi receipt printer once, and this sends it the standard ESC/POS drawer-kick command directly — no custom wrapper code needed. Most printers with a cash drawer port support this out of the box.
